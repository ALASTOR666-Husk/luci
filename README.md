## 🤔 Что такое Docker?

Представьте, что вы разработчик. На вашем компьютере код работает идеально, но когда вы отправляете его коллеге или на сервер, всё ломается из-за различий в версиях библиотек, операционной системы или переменных окружения.

**Docker решает проблему «У меня на машине работает».**

В отличие от виртуальных машин (VM), которые эмулируют целую операционную систему с ядром, **контейнеры Docker** используют ядро хост-системы, изолируя только процессы приложения. Это делает их:
*   🚀 **Быстрыми:** Запуск за секунды (иногда миллисекунды).
*   💾 **Легкими:** Занимают мегабайты, а не гигабайты.
*   📦 **Переносимыми:** Работают одинаково на Linux, Windows, macOS и в облаке.

## 📜 История появления и развития

История Docker — это история упрощения деплоя.

| Год | Событие | Значение |
| :--- | :--- | :--- |
| **2013** | **Рождение на PyCon** | Соломон Хайкс (Solomon Hykes) представил Docker как внутренний проект компании *dotCloud*. Это был момент «Вау!» для индустрии. |
| **2014** | **Взрыв популярности** | Docker Engine становится стандартом. Появляется Docker Hub. Крупные игроки (Google, Red Hat) начинают инвестировать в контейнеры. |
| **2015** | **Open Container Initiative (OCI)** | Чтобы избежать монополии, Docker передает спецификации формата контейнеров независимому сообществу OCI. |
| **2017** | **Проект Moby** | Docker Inc. разделяет проект на корпоративную версию (Docker Enterprise) и сообщество (Moby Project). |
| **2019** | **Продажа Enterprise** | Docker Inc. продает свой бизнес-сегмент компании *Mirantis*, фокусируясь исключительно на инструментах для разработчиков (Docker Desktop). |
| **2020+** | **Эра Kubernetes** | Docker становится стандартом для *разработки*, в то время как Kubernetes доминирует в *оркестрации* на продакшене. |

## 🛠️ Экосистема Docker

Docker — это не одна программа, а набор инструментов.

### 🌐 Docker Hub
Это «App Store» для контейнеров. Глобальный реестр, где хранятся миллионы готовых образов.
*   **Официальные образы:** Поддерживаются разработчиками ПО (например, `nginx`, `postgres`, `python`).
*   **Пользовательские образы:** Создаются сообществом.
*   **Пример использования:**
    ```bash
    docker pull nginx
    ```

### 📄 Dockerfile
Это текстовый документ («рецепт»), содержащий инструкции по сборке образа. Docker читает этот файл и автоматически создает образ.

**Пример простого Dockerfile (Python):**
```dockerfile
# Базовый образ
FROM python:3.9-slim

# Рабочая директория внутри контейнера
WORKDIR /app

# Копирование зависимостей и установка
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Копирование кода приложения
COPY . .

# Команда запуска
CMD ["python", "app.py"]
