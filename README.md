## 🧐 Что такое Docker?

Docker — это инструмент, который реализует концепцию **контейнеризации**. В отличие от виртуальных машин (VM), которые эмулируют целое оборудование и ОС, контейнеры используют ядро хост-операционной системы, но изолируют процессы, файловую систему и сеть.

### Ключевые преимущества:
*   🚀 **Скорость:** Контейнеры запускаются за секунды.
*   📦 **Портативность:** "Работает на моей машине" больше не проблема.
*   🛡️ **Изоляция:** Приложения не конфликтуют друг с другом.
*   📉 **Легковесность:** Меньше накладных расходов на ресурсы по сравнению с VM.

## 📜 История появления и развития

Путь Docker от внутреннего проекта до индустриального стандарта:

| Год | Событие |
| :--- | :--- |
| **2010** | Компания **dotCloud** начинает работу над внутренним проектом контейнеризации. |
| **2013** | Docker представлен как проект с открытым исходным кодом на конференции PyCon. Взрывной рост популярности. |
| **2014** | Релиз **Docker 1.0**. Компания переименовывается в Docker Inc. |
| **2015** | Появление **Docker Swarm** (оркестрация) и рост конкуренции с Kubernetes. |
| **2017** | Docker Inc. передает проект контейнеризации (containerd) в **CNCF** (Cloud Native Computing Foundation). |
| **2019** | Docker Enterprise продан компании **Mirantis**. Docker Inc. фокусируется на Docker Desktop и инструментах для разработчиков. |
| **2020** | Введение платной подписки для **Docker Desktop** в крупных компаниях. |
| **2024** | Docker остается стандартом де-факто для локальной разработки, несмотря на рост альтернатив (Podman, Rancher). |

## 🌍 Современное состояние экосистемы

Сегодня Docker находится в зрелой стадии развития.

1.  **Стандарт разработки:** Почти каждый бэкенд-разработчик использует Docker для поднятия баз данных, кэшей и окружения.
2.  **Kubernetes (K8s):** В продакшене для оркестрации тысяч контейнеров чаще используется Kubernetes, а не Docker Swarm. Docker Engine часто используется как "рантайм" для K8s (через containerd).
3.  **Альтернативы:** Из-за лицензионной политики Docker Desktop, некоторые компании переходят на **Podman** или **Rancher Desktop**.
4.  **Безопасность:** Усиленный фокус на сканирование образов на уязвимости (Docker Scout).

## 📦 Docker Hub и готовые образы

**Docker Hub** — это облачный реестр для хранения и обмена образами контейнеров.

### Как это работает:
1.  **Public Images:** Бесплатные образы от сообщества и вендоров (nginx, python, redis).
2.  **Private Images:** Закрытые репозитории для вашего кода.
3.  **Automated Builds:** Автоматическая сборка образа при пуше в GitHub/GitLab.

### Пример использования:
```bash
# Поиск образа
docker search nginx

# Скачивание образа
docker pull nginx:latest

# Запуск контейнера из образа
docker run -d -p 80:80 --name my-web-server nginx
